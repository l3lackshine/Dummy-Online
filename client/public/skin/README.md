# skin/ (ไฟล์รวมที่สร้างอัตโนมัติ)

`skins.json` และ `gacha.json` ในโฟลเดอร์นี้ถูก **สร้างจากโฟลเดอร์ Character / Item / Shop** ด้วย `node scripts/build-assets.js` — แก้ที่ต้นทางแล้วรันสคริปต์ ไม่ต้องแก้สองไฟล์นี้ด้วยมือ

โครงสร้างและวิธีเพิ่มตัวละคร/ไอเทม/ตู้กาชา ดูที่ `ASSETS.md` ในโฟลเดอร์หลักของโปรเจกต์

ไฟล์อื่นในโฟลเดอร์นี้: `skills.json` (สกิล), `skill-editor.html` / `skill-studio.html` (เครื่องมือแก้สกิล)
