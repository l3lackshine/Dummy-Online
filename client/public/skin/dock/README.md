# สกินแผงไพ่และปุ่มของเรา (dock)

แผงล่างของหน้าเล่น = ตัวละครของเรา + ไพ่ในมือ + ปุ่มเรียงไพ่ + ปุ่ม เกิด/ฝากออโต้/ทิ้ง/ออก
สกินนี้ใช้เฉพาะฝั่งเรา (คนอื่นไม่เห็น) เลือกได้ที่ หน้าแรก ("สกินแผงไพ่และปุ่ม") หรือหน้าร้านค้า

## โฟลเดอร์
- `panels/`  รูปพื้นหลังแผง (แนะนำ WebP/PNG กว้าง 780-1080px สูง 360-480px ยืดเต็มแผงแบบ 100% x 100%)
- `buttons/` รูปปุ่ม (WebP/PNG โปร่งใส ขนาดราว 320x120px ยืดเต็มปุ่ม ปุ่มทุกปุ่มใช้รูปเดียวกัน สีปุ่มยังมาจาก `buttons` ด้านล่าง)

## ลงทะเบียนใน `../skins.json` หมวด `docks`
```json
{ "id": "my-skin", "name": "ชื่อที่แสดง",
  "panel": "linear-gradient(#0000,#0004)",       // พื้นหลังแบบ CSS (ใช้เมื่อไม่มี panelAsset)
  "panelAsset": "./skin/dock/panels/my.webp",     // รูปพื้นหลังแผง (ไม่บังคับ)
  "border": "#ffffff30",                          // สีขอบแผง
  "buttonAsset": "./skin/dock/buttons/my.webp",   // รูปปุ่ม (ไม่บังคับ)
  "buttons": { "blue": ["#บน","#ล่าง","#เงา"], "org": [..], "grn": [..], "g": [..], "tool": [..] } }
```
`blue` = เกิด, `org` = ทิ้ง/คว่ำน็อก, `grn` = ฝากออโต้, `g` = ออก, `tool` = ปุ่มเรียงไพ่/ซ้าย/ขวา
