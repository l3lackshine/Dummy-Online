🛠 Skill Studio — ค่าความสามารถ · ดาว · สกิลของตัวละคร

ค่าความสามารถ ผูกกับตัวละคร: ค่า = ค่าเริ่มต้น + เพิ่มต่อดาว × (ดาว − 1) · ผู้เล่นอัพ "ดาวตัวละคร" (เสียเหรียญ) แล้วค่าเพิ่มตามนี้ · แก้เสร็จกด ดาวน์โหลด skills.json วางที่ client/public/skin/skills.json และกด คัดลอก SQL ไปรันใน Supabase SQL Editor (ให้ฐานข้อมูลรู้จำนวนตัวซ้ำที่ใช้อัพดาว/โบนัสเหรียญ — ไม่งั้นจำนวนจริงใช้ค่ากลาง)

ค่าความสามารถ (Stats) — ชนิดของค่า

ค่าเริ่มต้นของทุกตัวละคร (ใช้เมื่อตัวละครไม่ได้ตั้งเอง)

ตัวละคร

ตัวละครอ่านจาก skins.json — ตั้งค่า/ผูกสกิลให้แต่ละตัวได้เลย (ตัวที่ไม่ได้ตั้งจะใช้ค่าเริ่มต้นด้านบน)

สกิล

SQL สำหรับฐานข้อมูล (character_defs)
