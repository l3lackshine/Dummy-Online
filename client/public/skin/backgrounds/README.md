# พื้นหลังที่นั่งของผู้เล่น (กรอบรูปล้อมโต๊ะ)

แต่ละผู้เล่นมีพื้นหลังของตัวเอง (ผู้เล่นเลือกเอง บอทสุ่ม ทุกคนเห็นพื้นหลังของกันและกัน)
พื้นหลังของ 4 ที่นั่งประกอบเป็นกรอบรูปรอบโต๊ะ ตัดทแยงที่มุมโต๊ะ (บน/ซ้าย/ขวา/ล่าง)

## ไฟล์ภาพ
- ฉากแนวตั้ง สัดส่วนประมาณ 3:4 (เช่น 900x1200px) WebP/PNG/SVG ภาพจะถูกขยายแบบ cover เต็มกรอบ แต่ละที่นั่งเห็นเฉพาะส่วนของตัวเอง
  ครึ่งบน = ผนัง/หน้าต่าง/ไฟ, กลาง = โปสเตอร์/โคมไฟ, ล่าง = โต๊ะ/ชิป/ไพ่ (ตามภาพอ้างอิง) — ส่วนกลางภาพจะถูกโต๊ะบัง
- `room-*.svg` สร้างจากสคริปต์ (ฉากตัวอย่าง) แทนที่ด้วยภาพจริงได้โดยใช้ชื่อไฟล์เดิมหรือลงทะเบียนใหม่

## ลงทะเบียน `../skins.json` หมวด `backgrounds`
`{ "id", "name", "asset": "./skin/backgrounds/xxx.webp" หรือ "css": "linear-gradient(...)", "ink": "#ffffff" }`
เพิ่ม id ใหม่ต้องเพิ่มใน `BGS` ที่ `server/src/engine.js` ด้วย แล้ว deploy ทั้งสองฝั่ง
