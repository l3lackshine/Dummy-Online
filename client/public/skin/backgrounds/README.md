# พื้นหลังที่นั่งของผู้เล่น

แต่ละผู้เล่นมีพื้นหลังที่นั่งของตัวเอง (ผู้เล่นเลือกเอง บอทสุ่ม) ทุกคนในห้องเห็นพื้นหลังของกันและกัน
ไม่ใช่พื้นหลังหน้าเว็บอันเดียวทั้งหน้าอีกต่อไป

ลงทะเบียนใน `../skins.json` หมวด `backgrounds`: `{ "id", "name", "css" หรือ "asset": "./skin/backgrounds/xxx.webp", "ink": "สีตัวอักษรบนพื้นหลังนี้" }`
เพิ่มพื้นหลังใหม่ต้องเพิ่ม id เดียวกันใน `BGS` ที่ `server/src/engine.js` แล้ว deploy ทั้งสองฝั่ง (เซิร์ฟเวอร์ตรวจ id ที่อนุญาต)
