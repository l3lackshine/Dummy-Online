# ตั้งค่าระบบล็อกอิน (Supabase) — ทำครั้งเดียว

1. สมัคร https://supabase.com → **New project** (ตั้งรหัสผ่านฐานข้อมูล เลือก region ใกล้ไทย เช่น Singapore)
2. เมนู **SQL Editor** → วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด → **Run** (v2: มีตารางสถิติ/เควสต์/ร้านค้า/รางวัลล็อกอิน รันทับของเดิมได้ ข้อมูลไม่หาย)
3. เมนู **Authentication → Providers → Email**: ปิด **Confirm email** (ถ้าอยากให้สมัครแล้วเล่นได้ทันที) แล้ว Save
4. เมนู **Project Settings → API** คัดลอก 2 ค่า: **Project URL** และ **anon public key**
5. ใส่ใน `client/public/config.js` (ค่า anon key เปิดเผยได้ ปลอดภัยด้วย RLS):
   `SUPABASE_URL: 'https://xxxx.supabase.co'`, `SUPABASE_ANON_KEY: 'eyJ...'`
6. ที่ **Render → เซิร์ฟเวอร์เกม → Environment** เพิ่ม `SUPABASE_URL` และ `SUPABASE_ANON_KEY` (ค่าเดียวกัน) แล้ว Deploy ใหม่
7. อัปขึ้น GitHub → workflow สร้าง APK ตัวใหม่ให้เอง

ปล่อยค่าใน config.js ว่าง = ปิดระบบล็อกอิน เกมทำงานแบบเดิม

**ปรับรางวัล/เควสต์/ราคา:** แก้ตัวเลขในส่วน "ข้อมูลตั้งต้น" ท้ายไฟล์ `schema.sql` แล้ว Run ซ้ำ (รางวัลล็อกอิน 7 วัน, เควสต์รายวัน/สัปดาห์, ราคาสินค้า)
**MCash:** ตอนนี้เป็นช่องเก็บยอดอย่างเดียว (แสดงในเกม) การเติมเงินจริงต้องต่อระบบชำระเงินแล้วให้ฝั่งเซิร์ฟเวอร์เพิ่มยอดด้วย service key — ยังไม่ได้ทำ

**หมายเหตุ:** ล็อกอินด้วยอีเมล+รหัสผ่านและผู้เล่นชั่วคราว (Google ล็อกอินใน WebView ยังไม่ได้ทำ) · ผลเกมถูกส่งจากแอปไปบันทึกผ่านฟังก์ชันในฐานข้อมูล ผู้เล่นที่รู้เทคนิคยังส่งผลปลอมได้ ถ้าจะกันโกงเต็มที่ให้ให้เซิร์ฟเวอร์เกม (Node) เป็นผู้เรียก record_game ด้วย service key แทน
