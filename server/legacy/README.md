# legacy — ของเก่าที่ย้ายออกจากชุดหลัก (ไม่ได้ลบ)

- `rules/oldmaid/`, `rules/simple-cards.js` — กฎ "อีแก่" รุ่นแรก ไม่มี `index.js` จึงไม่เคยถูกลงทะเบียน ปัจจุบันใช้ `src/rules/eekae/` แทน
- `test-simple-rules.js`, `test-simple-online.js` — เทสต์ของรุ่นนั้น (ผู้เล่น 6 คน/oldmaid/กระเป๋าเหรียญฝั่งเซิร์ฟเวอร์) ล้มเหลวกับโค้ดปัจจุบัน และไม่อยู่ใน `npm test` ชุดเทสต์ปัจจุบันของทุกเกมคือ `test-games.js`

ย้ายกลับได้ถ้าจะกลับมาใช้ แต่ต้องแก้ path ของ `require` และปรับให้ตรงกับกติกาปัจจุบัน
