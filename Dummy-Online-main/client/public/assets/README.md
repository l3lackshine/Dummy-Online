# Assets

นำรูปภาพจริงมาใส่โฟลเดอร์นี้ได้ เช่น:
- `logo.png` โลโก้เกม
- `cards/` รูปหน้าไพ่ 52 ใบ
- `card-backs/` รูปหลังไพ่แต่ละสกิน
- `backgrounds/` ภาพพื้นโต๊ะ
- `buttons/` ปุ่มภาพ
- `avatars/` รูปโปรไฟล์ผู้เล่น
- `icons/` ไอคอน UI

ต้นแบบนี้วาดไพ่และตัวอย่างสกินด้วย HTML/CSS เพื่อให้รันได้ทันทีโดยไม่ต้องดาวน์โหลดภาพภายนอก ยกเว้นฟอนต์ Google และ Socket.IO CDN.
