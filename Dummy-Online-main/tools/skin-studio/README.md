# Skin Studio (แอป Android)

แอปสำหรับเพิ่มสกินเข้าเกม ตั้งราคาของในร้านค้า แล้วอัปโหลดขึ้น GitHub ได้จากมือถือ — **GitHub Actions เป็นคนสร้างไฟล์ APK ให้** ไม่ต้องลง Android Studio

## ติดตั้งแอป
1. push โฟลเดอร์นี้ขึ้น repo (พร้อมไฟล์ `.github/workflows/skin-studio-apk.yml`)
2. ที่ GitHub → แท็บ **Actions** → เลือก **Build Skin Studio APK** → รอให้ขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 3–6 นาที)
3. โหลด `.apk` จาก **Releases** ของ repo (หรือจาก Artifacts ใน run นั้น) แล้วติดตั้งบนมือถือ (ต้องอนุญาต "ติดตั้งจากแหล่งอื่น")
   - APK เป็นแบบ debug ที่ GitHub เซ็นให้อัตโนมัติ ใช้ส่วนตัวได้เลย ถ้าต้องการอัปเดตทับของเดิม ให้ติดตั้งจาก run ที่ใหม่กว่า (ลายเซ็น debug ของแต่ละ run อาจต่างกัน ถ้าติดตั้งทับไม่ได้ให้ถอนแอปเก่าก่อน — ข้อมูลตั้งค่าในแอปจะหาย)

## ตั้งค่าครั้งแรก (แท็บ ⚙️)
- เจ้าของ repo / ชื่อ repo / branch (`main`)
- **GitHub Token**: GitHub → Settings → Developer settings → Personal access tokens → *Fine-grained tokens* → เลือกเฉพาะ repo ของเกม → Permissions → **Contents: Read and write**
- ค่าเริ่มต้นตรงกับโปรเจกต์เกม: โฟลเดอร์สกิน `client/public/skin`, ไฟล์ id เซิร์ฟเวอร์ `server/src/rules/common.js`
- กด **ทดสอบการเชื่อมต่อ** แล้วกด **โหลดสกินจาก GitHub**

## วิธีใช้
| แท็บ | ทำอะไร |
|---|---|
| 🛍️ ร้านค้า | ดูของทุกหมวด แก้ราคา (0 = ฟรี ไม่ขึ้นร้านค้า, > 0 = ขายในร้าน) แก้ชื่อ ลบ |
| ➕ เพิ่มสกิน | พื้นหลัง / ตัวละคร / หลังไพ่ / โต๊ะ / ธีมสี — กรอกชื่อ id ราคา เลือกรูปหรือสี |
| 🚀 อัปโหลด | ดูรายการที่ค้าง แล้วกดอัปโหลด — ทุกอย่างขึ้นเป็น **commit เดียว** |

- รายการที่ยังไม่อัปโหลดเก็บไว้ในเครื่อง ปิดแอปแล้วยังอยู่
- ตอนอัปโหลดแอปดึง `skins.json` ล่าสุดจาก GitHub มาแก้ใหม่ทุกครั้ง จึงไม่ทับงานที่ push จากเครื่องอื่น (ถ้าชนกันจริงจะแจ้งให้ลองใหม่)
- รูปแรสเตอร์ถูกย่อและแปลงเป็น WebP ให้อัตโนมัติ (ปิดได้) SVG อัปโหลดตามเดิม
- **ตัวละครและพื้นหลัง**: เซิร์ฟเวอร์ตรวจ id ของผู้เล่น (`CHARS` / `BGS` ใน `server/src/rules/common.js`) แอปเพิ่ม/ลบ id ให้ใน commit เดียวกัน ไม่งั้นผู้เล่นคนอื่นจะไม่เห็นสกินนั้น
- หลัง push แล้ว Render ต้อง deploy ใหม่ (ทั้ง client และ server ถ้ามีเพิ่มตัวละคร/พื้นหลัง) เกมถึงจะเห็นของใหม่

## ที่ยังไม่รองรับ
สกิน `docks` และ `cards` (แก้ใน `skins.json` ตรง ๆ ตาม `client/public/skin/dock/README.md`) · แก้สีของสกินที่มีอยู่ (แก้ได้เฉพาะชื่อ/ราคา/ลบ)

## สำหรับนักพัฒนา
- ตรรกะอยู่ใน `app/src/main/assets/core.js` (ไม่แตะ DOM) · หน้าจอ `app.js` · ตัวแอป Kotlin (`MainActivity.kt`) เป็นแค่ WebView
- ทดสอบ: `node test/test-core.js` และ `node test/test-app.js` (GitHub และ DOM จำลอง) — workflow รันทั้งสองก่อนสร้าง APK
- สร้างเองในเครื่อง: `gradle :app:assembleDebug` (Gradle 8.9, JDK 17)
