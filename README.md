# Dummy Online — Reference Gameplay

เกมไพ่ดัมมี่ภาษาไทย ใช้กติกาและรูปแบบการเล่นจากไฟล์อ้างอิง `ไพ่ดัมมี่ — ลองเล่นคนเดียว` และรองรับห้องออนไลน์ผ่าน Socket.IO

## ความสามารถ
- โต๊ะเล่น 4 ที่นั่ง สูงสุด 4 ผู้เล่นจริง
- หากมีผู้เล่นจริงไม่ครบ 4 ที่นั่ง ระบบเติมบอทให้ครบ 4 ที่นั่ง
- โหมดเล่นคนเดียวกับบอท โดยเริ่มเกมได้ทันที
- แตะไพ่ตำแหน่งใดก็ได้ในกองทิ้งเพื่อเก็บไพ่ใบนั้นและไพ่ที่อยู่ด้านบน
- ไพ่ที่เก็บต้องนำไพ่ที่เลือกมาเกิดอย่างน้อย 1 ชุด แต่ไม่บังคับให้เกิดไพ่ทุกใบที่เก็บมา
- ลงชุดไพ่เรียง/ตอง, ฝากไพ่เข้าชุดที่เกิดแล้ว, ฝากอัตโนมัติ และน็อก
- ไพ่ในมือเลื่อนซ้าย–ขวาได้ ไพ่ไม่หายเมื่อมีหลายใบ
- ธีมไพ่และเหรียญตัวอย่างเก็บไว้ในเบราว์เซอร์ของอุปกรณ์

## โครงสร้าง
- `client/public/` — หน้าเกมและ UI
- `server/src/rules/` — กฎเกมแยกเป็นโฟลเดอร์ต่อกฎ (ดู `server/src/rules/README.md`)
- `server/src/engine.js` — ทางลัดไปยังกฎดัมมี่ (คงไว้ให้ชุดทดสอบเดิม)
- `server/src/index.js` — เซิร์ฟเวอร์ Socket.IO

## รันเซิร์ฟเวอร์

```bash
cd server

```

## Deploy บน Render
- Backend Root Directory: `server`
- Build Command: `npm install`
- Start Command: `npm start`
- ตั้ง `CLIENT_ORIGIN` ได้หากต้องการจำกัด origin; หากไม่ตั้ง จะอนุญาตทุก origin
- Static Site Root Directory: `client`
- Publish Directory: `public`
- ไฟล์ `client/public/config.js` ต้องชี้ไปยัง URL ของ Backend

## บันทึกการแก้บั๊ก (v4)
- **เกมค้างหลังเก็บไพ่กองทิ้ง** (ร้ายแรง): `canTake` เคยอนุญาตเก็บไพ่ที่เกิดชุดได้แต่ต้องใช้ไพ่ทั้งมือ ทำให้ต้องเหลือไพ่ ≥ 1 ใบไม่ได้ → เกิดไม่ได้ ทิ้งไม่ได้ เกมค้างถาวร (บอทถูกบังคับยกเลิก `must` เงียบ ๆ) ตอนนี้เก็บได้เฉพาะเมื่อเกิดแล้วยังเหลือไพ่ในมือ
- **เซิร์ฟเวอร์ล้มทั้งตัวเมื่อ client ส่ง `null`**: handler แบบ `({name} = {})` throw กับ `null` → ห่อทุก handler ด้วย try/catch และรับ payload เฉพาะ object
- **ที่นั่งเลื่อนผิด**: เดิมใช้ลำดับใน `room.players` เป็นที่นั่ง คนออกหลังเกมจบแล้วที่นั่งเลื่อน และคนที่เข้าห้องหลังเกมจบได้รับ state ของ *บอท* (เห็นไพ่บอท) ตอนนี้ผู้เล่นแต่ละคนมี `seat` ของตัวเอง
- **เจ้าของห้องย้ายแล้วไม่มีปุ่มเริ่ม/เล่นอีกตา**: server ส่ง `youHost` ใน `room:lobby` และ client อัปเดตตาม
- **รีเฟรชหน้า/เน็ตหลุดแล้วเสียที่นั่ง**: เพิ่ม token + `room:rejoin` (เก็บใน localStorage) เชื่อมต่อกลับได้ที่นั่ง/ไพ่เดิม บอทที่รับช่วงถูกปลด; กดออกห้องเองจะไม่คืนที่นั่ง
- **ได้เหรียญซ้ำทุกครั้งที่รีเฟรชหลังเกมจบ**: จ่ายเหรียญครั้งเดียวต่อเกม (`gid`) และแสดงจำนวนที่ได้ไม่หายเมื่อมี state ใหม่
- **ห้องค้างในหน่วยความจำ**: ห้องที่ไม่มีคนจริงเชื่อมอยู่ถูกลบหลัง 2 นาที (`EMPTY_ROOM_TTL_MS`)
- **กันสแปม/ข้อมูลขยะ**: rate limit ต่อ socket (`RATE_PER_SEC`, ค่าเริ่มต้น 20/วินาที), จำกัดจำนวนห้อง (`MAX_ROOMS`), ตัดชื่อ/ล้างอักขระควบคุม, จำกัดขนาด `ids`
- แก้ชื่อโปรเจกต์ "5 คน" → "4 คน" ให้ตรงกับโค้ด (`MAX_PLAYERS = 4`)

## ระบบสับไพ่ (v5)
- **เอนจิ้นสับไพ่แยกไฟล์**: `server/src/shuffle.js` — แทนไพ่ 52 ใบด้วยตัวอักษร `A-Z a-z` แล้วสับสตริงนั้นด้วยท่าสับจริง: `cut` (ตัดไพ่), `riffle` (สับรีฟเฟิลตามโมเดล Gilbert–Shannon–Reeds), `overhand` (สับโอเวอร์แฮนด์) แผนมาตรฐานรีฟเฟิลรวม 12 ครั้ง (ทดสอบแล้วว่า 8 ครั้งยังเอนเอียงเล็กน้อย) ใช้ `crypto.randomInt` เป็นตัวสุ่ม
  - `shuffle()` คืน `{ letters, ids, steps }` — `ids` คือลำดับไพ่จากบนสุดถึงล่างสุด ส่งเข้า `Engine.newGame(humans, { deck: ids })` ได้ทันที (ถ้าไม่ส่ง engine จะสับเองด้วยเอนจิ้นเดียวกัน)
- **ปุ่มสับไพ่**: ในล็อบบี้และหน้าจบตา (event `game:shuffle`) — **ทุกห้อง (รวมห้องเล่นกับบอทคนเดียว) ต้องกดสับก่อนจึงเริ่มเกมได้ในทุกตา**
- **ใครมีสิทธิ์สับ**: ตาแรกคือเจ้าของห้อง · ตาถัดไปคือ **ผู้ชนะตาก่อนหน้า** (คนน็อก; ถ้าไพ่หมดกองคือคนแต้มสูงสุด) · ถ้าผู้ชนะเป็นบอท/ออกจากห้อง/หลุดการเชื่อมต่อ สิทธิ์กลับไปที่เจ้าของห้อง · ปุ่ม "เริ่มเกม/เล่นอีกตา" ยังเป็นของเจ้าของห้อง
- สำรับที่สับแล้วใช้ได้ครั้งเดียว (ตาถัดไปต้องสับใหม่) และ**ไม่ถูกส่งไปหา client** — ส่งเพียงสถานะ `shuffle.ready` กับชนิดท่าสับสำหรับแอนิเมชัน
- ทดสอบ: `test-shuffle.js` (ท่าสับ, χ² / ลำดับขึ้น / คู่ติดกัน 30,000 ครั้ง, การแจกไพ่) และส่วน [7] ใน `test-online.js` (สิทธิ์ผู้ชนะทุกกรณี)

## หน้าแรกใหม่ + หน้าย่อย (v6)
- **หน้าแรก** (`homeView`): ฉากห้องญี่ปุ่นซากุระ ตัวละครที่เลือกอยู่ซ้าย ป้ายไม้ 3 ป้ายขวา — เล่นเกม / ร้านค้า / โปรไฟล์ (ภาพป้ายอยู่ใน `client/public/ui/`)
- **เล่นเกม** (`playView`): ป้าย เล่นคนเดียว · สร้างห้อง · เข้าห้อง (กดเข้าห้องแล้วกรอกรหัส) — ป้ายเปล่า `ui/sign-blank.webp` สร้างจากป้ายร้านค้าเดิม ตัดตัวหนังสือออก
- **ร้านค้า** (`shopView`): แสดงเฉพาะของที่มีราคา (`price` ใน `skins.json`) ซื้อด้วยเหรียญ ของที่ซื้อเก็บใน `dummyOwned` แบบ `kind:id`
- **โปรไฟล์** (`profileView`): ตั้งชื่อ เลือกตัวละคร / หลังไพ่ / สกินโต๊ะ / พื้นหลัง (เลือกได้เฉพาะที่เป็นเจ้าของ รายการราคา 0 ใช้ได้ทันที)
- **พื้นหลังเดียวกันทุกห้อง**: ใช้พื้นหลังที่เลือกเป็นพื้นหลังหน้าเว็บทุกหน้ารวมถึงหน้าเกม เลิกใช้กรอบพื้นหลังรายที่นั่ง (server ยังรับ `bg` ได้เหมือนเดิมแต่ client ไม่ใช้แล้ว)
- **หลังไพ่ใหม่** (`backs` ใน `skins.json`): SVG ใน `skin/cards/backs/` — เพิ่มได้โดยไม่ต้องแก้โค้ด
- ตัวละคร `boy` / `girl` เปลี่ยนเป็นภาพใหม่ (id เดิม เซิร์ฟเวอร์ไม่ต้องแก้)
- สไตล์ใหม่อยู่ใน `client/public/ui.css` (โหลดหลัง `style.css`) · ฟอนต์ Mali/Sarabun จาก Google Fonts

- **แยกกฎออกจากตัวเกม** `server/src/rules/` — ทะเบียนกฎ + โฟลเดอร์ `dummy/` (meta / engine / scoring / cards) เซิร์ฟเวอร์ส่งรายการกฎมาให้ client (`rules:list`) หน้า "สร้างห้อง/เล่นคนเดียว" จึงมีให้เลือกไพ่และตั้งค่าตามที่กฎประกาศ เพิ่มกฎใหม่โดยไม่ต้องแก้ client
- **เหรียญเดิมพันของดัมมี่** ผู้สร้างห้องตั้ง "ตัวละ N เหรียญ" (ค่าเริ่มต้น 20) แล้วคิดตามนี้
  - **น็อก**: คนที่ไม่น็อกจ่ายให้คนน็อก — อันดับสุดท้าย ×1 · อันดับ 3 ×0.75 · อันดับ 2 ×0.5 (ตัวละ 20 → 20 / 15 / 10) จัดอันดับตามแต้มท้ายเกม
  - **ตีปี้**: ไพ่ใบไหนที่ทิ้งไว้แล้วถูกคนอื่นเก็บไปเกิด (ทั้งสเปโตและไพ่ธรรมดา) คนทิ้งจ่ายให้คนเกิด N ต่อใบ
  - **อมสเปโต**: จบเกมแล้วยังถือสเปโตอยู่ จ่าย N ต่อใบ ให้ทุกคนรอบวง (ตั้งเป็น "เฉพาะคนน็อก" ได้) ถ้าทั้งเกมไม่เคยเกิดเลยจ่าย ×2
  - เหรียญรวมทุกคนในตานั้นเป็น 0 เสมอ; เหรียญของผู้เล่นไม่ต่ำกว่า 0; จ่ายครั้งเดียวต่อเกม
- **สับไพ่ที่โต๊ะ**: เข้าห้อง/เริ่มเล่นคนเดียวแล้วอยู่ที่โต๊ะเลย สับที่กองกลางโต๊ะ (เห็นท่าสับ) แล้วกดเริ่มเกม
- **แจกไพ่ทีละใบ**: หลังกดเริ่มเกม ไพ่บินจากกองจั่วไปหาผู้เล่นทีละใบวนรอบ (แตะที่โต๊ะเพื่อข้าม; ปิดอัตโนมัติถ้าเครื่องตั้งลดการเคลื่อนไหว; ตั้ง `DEAL_MS` ใน `config.js` เพื่อปรับความเร็ว หรือ `0` เพื่อปิด)
- ทดสอบ: `cd server && npm test` (เพิ่ม `test-scoring.js`)

## เกมไพ่ไทยที่เพิ่ม (v7.1)

หลังกด **เล่นเกม** จะเข้าหน้า **เลือกเกม** ก่อน (ดัมมี่ · ป๊อกเด้ง · เก้าเก · ผสมสิบ · อีแก่) แล้วค่อยเลือก เล่นคนเดียว / สร้างห้อง / เข้าห้อง
กติกาอยู่ที่ `server/src/rules/<เกม>/` (เซิร์ฟเวอร์ตัดสินทั้งหมด) · หน้าโต๊ะอยู่ที่ `client/public/games.js` · ข้อความกติกาและการนับเหรียญแสดงในหน้าตั้งค่าห้องและปุ่ม 📖 กติกา

| เกม | การนับเหรียญ (เดิมพัน = stake) |
|---|---|
| ป๊อกเด้ง | เล่นกับเจ้ามือ: ผู้ชนะได้ stake × เด้งของไพ่ฝั่งชนะ · แต้ม/ประเภทเท่ากัน เทียบเด้งจ่ายส่วนต่าง (ตั้ง "เสมอ" ได้) · ตองชนสามเหลือง ได้ส่วนต่าง 2 เท่า |
| เก้าเก | ทุกคนลงค่าต๋ง stake เข้ากองกลาง · หมอบ/สู้/ตาม/เกทับ (เกทับ ≤ 3 ครั้ง) · ผู้ชนะกวาดกอง เสมอแบ่งเท่ากัน |
| ผสมสิบ | ผู้ชนะ (ครบ 3 คู่) รับ stake จากผู้แพ้ทุกคน · มือพิเศษตั้งให้ ×1 หรือ ×2 |
| อีแก่ | ผู้ถือควีนเดี่ยวสุดท้ายแพ้ จ่ายทุกคนที่รอดคนละ stake หรือจ่ายคนหมดไพ่ก่อนคนเดียว |

ส่วนที่ต้นฉบับกติกาไม่ได้กำหนดตายตัว (ตัวเลือกในหน้าตั้งค่าห้อง ปรับได้ที่ `meta.js` ของแต่ละเกม): การเสมอแต้มของป๊อกเด้ง, ไพ่เรียงในป๊อกเด้ง, ขั้นเกทับของเก้าเก, รูปแบบภูเก็ต/แบบง่ายของผสมสิบ, โหมดจ่ายของอีแก่
