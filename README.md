# Dummy Online — Reference Gameplay

เกมไพ่ดัมมี่ภาษาไทย ใช้กติกาและรูปแบบการเล่นจากไฟล์อ้างอิง `ไพ่ดัมมี่ — ลองเล่นคนเดียว` และรองรับห้องออนไลน์ผ่าน Socket.IO

## ความสามารถ
- โต๊ะเล่น 4 ที่นั่ง สูงสุด 4 ผู้เล่นจริง
- หากมีผู้เล่นจริงไม่ครบ 4 ที่นั่ง ระบบเติมบอทให้ครบ 4 ที่นั่ง
- โหมดเล่นคนเดียวกับบอท โดยเริ่มเกมได้ทันที
- แตะไพ่ตำแหน่งใดก็ได้ในกองทิ้งเพื่อเก็บไพ่ใบนั้นและไพ่ที่อยู่ด้านบน
- ไพ่ที่เก็บต้องนำไพ่ที่เลือกมาเกิดอย่างน้อย 1 ชุด แต่ไม่บังคับให้เกิดไพ่ทุกใบที่เก็บมา
- ลงชุดไพ่เรียง/ตอง, ฝากไพ่เข้าชุดที่เกิดแล้ว, ฝากอัตโนมัติ และน็อก
- ไพ่ในมือเลื่อนซ้าย–ขวาได้ ไพ่ไม่หายเมื่อมีหลายใบ
- ธีมไพ่และเหรียญตัวอย่างเก็บไว้ในเบราว์เซอร์ของอุปกรณ์

## โครงสร้าง
- `client/public/` — หน้าเกมและ UI
- `server/src/engine.js` — กติกาเกมและบอท
- `server/src/index.js` — เซิร์ฟเวอร์ Socket.IO

## รันเซิร์ฟเวอร์
```bash
cd server
npm install
npm start
```

## Deploy บน Render
- Backend Root Directory: `server`
- Build Command: `npm install`
- Start Command: `npm start`
- ตั้ง `CLIENT_ORIGIN` ได้หากต้องการจำกัด origin; หากไม่ตั้ง จะอนุญาตทุก origin
- Static Site Root Directory: `client`
- Publish Directory: `public`
- ไฟล์ `client/public/config.js` ต้องชี้ไปยัง URL ของ Backend


## อัปเดตล่าสุด: ระบบสกินและโต๊ะเกม

- เพิ่ม `client/public/skin/` พร้อมหมวด `characters`, `tables`, `backgrounds`, `cards` และไฟล์ `skins.json` สำหรับลงทะเบียนสกินโดยไม่แก้ `app.js`
- เข้าเมนูร้านค้า > ของตกแต่งเพิ่มเติม เพื่อเลือกสกินแต่ละหมวด
- โต๊ะเกมขยายใหญ่ขึ้น และแสดงผู้เล่นแยกตำแหน่งรอบโต๊ะ
- กดกองจั่วเพื่อเปิดหน้าต่างที่เลือกได้ว่าจะจั่วจากกองจั่วหรือเลือกไพ่จากกองทิ้ง โดยหน้าต่างแสดงไพ่กองทิ้งทั้งหมด
- การเก็บกองทิ้งยังยึดกติกาเดิมของ engine: เก็บไพ่ที่เลือกพร้อมไพ่ที่ทิ้งภายหลัง และต้องเกิดชุดโดยใช้ไพ่ใบแรกที่เลือก
